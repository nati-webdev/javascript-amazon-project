Amazon Clone

An Amazon-inspired e-commerce website built using HTML, CSS, and JavaScript. This project helped me practice front-end development by implementing real-world shopping functionality.

Live Demo

"View Live Website" (https://nati-amazon-shopping.netlify.app)

Features

- Product Display: Displays products dynamically from the backend API.
- Product Search: Search products by name and keywords.
- Shopping Cart: Add products, update quantities, and remove items.
- Checkout: Review cart items and select delivery options.
- Order Management: Place orders and view previous orders.
- Order Tracking: Track orders and view delivery progress.
- Buy Again: Add previously purchased products to the cart.
- Data Persistence: Uses localStorage to preserve cart data.

Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Day.js
- Git and GitHub

Project Structure

- "amazon.html" – Main shopping page
- "checkout.html" – Checkout page
- "orders.html" – Order history
- "tracking.html" – Order tracking
- "scripts/" – JavaScript functionality
- "styles/" – CSS styles
- "images/" – Project images
